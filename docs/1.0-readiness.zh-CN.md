# MusicServer 1.0 验收记录

更新日期：2026-09-20。发布版本：**1.0.0**。普通使用说明见 [第一次和 MusicServer 相遇](getting-started.zh-CN.md)。

## 1.0：流叶与开屏

- 背景增加缓慢下沉、翻转、错落漂移的绿色叶片，沿用水面动画时钟；叶片在透明时循环，窗口隐藏或启用减少动态效果时停止动画。
- 开屏以水滴、波纹和新叶展开表现生命流动，不增加固定等待时间。后台准备移出窗口初始化线程，主界面在服务身份验证成功后自动打开；启动中关闭窗口会取消后续服务启动。
- 人物图边缘融合进背景；日推按七首稳定分组，点击候选只交换本组的中心歌曲，最后一组保留余数，不再通过滑动整个候选池造成重复浏览。
- 改动已在隔离数据目录的实际 Tauri APP 验证：正常自动启动、源码禁用、固定端口占用时切换动态端口、本地播放、推荐翻页、1440×900 与 960×640 布局，以及正常关闭和启动中关闭的服务清理。减少动态效果时画布保持静止，恢复后继续绘制。
- 正式版同步 Cargo、Tauri 和页面版本号。每个发布提交的完整 state、api、desktop-build 结果以对应 Release 链接的 CI 为准；干净 Windows 静默安装由 desktop-build 验证，本地有运行中的用户 APP 时不执行静默安装。
- 发布验收发现并修复：全新数据目录尚未创建 SQLite 时，UI 进程也必须解析环境指定的曲库路径，避免首次启动时界面显示空库而 API 已读到外部曲库。新增真实进程回归覆盖首次读取及后续文件刷新。

以下保留此前候选版本的验收证据，供回归问题追溯。

## RC6：恢复正常启动与流麻水庭

- 复现 RC5 故障：全部六个固定端口已被旧服务占用，APP 未启动自己的后台，停在 `tauri.localhost` 内置页面；音乐库、日推与目录设置请求得到 HTML 而非 JSON。上一轮手动服务端口的 WebView 验证没有覆盖正常启动，不能作为启动通过的依据。
- 固定端口不可用时最多尝试两组系统分配的空闲端口。旧服务只有构建标识和 APP-home 范围都匹配才可复用；不同数据目录的同版本服务也不会串用。原生目录操作授权绑定实际验证过的 UI 地址。启动失败显示独立恢复页和可重试入口，不启动主界面轮询；原因记录在 `logs/desktop-startup.json`。
- 实际打包 APP 正常启动验证：六个旧端口保持占用；临时移开源码中的 UI、launcher、API 和 Core 后自动启动自己的服务并进入音乐树。全新空库有 14 首初遇推荐；原生文件夹窗口选择外置测试曲库，路径保存到 SQLite，重启后读取 13 首文件。整个过程没有手动启动 UI/API，也没有手动导航 WebView。
- 右侧改为透明流麻水庭：移除巨大尖头水滴，细枝、黄绿色浮叶和玻璃边缘构成层次；保留中心歌曲与六首候选，文字与按钮固定。雨滴波光改用断续、漂移、消散的波峰。1440×900、1280×820、960×640 实际 WebView 检查均为七首可见、按钮中心无遮挡、无横向溢出，翻页与播放中心偏差小于 1 px。
- 实测远程试听、选曲居中、点击空白水面换组及波纹，暂停/减少动态效果清空波纹、恢复后继续；浮叶遵守减少动态效果。隔离曲库喜欢《和煦的糖果风》后，约 26 秒完成真实下载和入库，再从音乐树播放，实际音源为本地媒体接口且时间正常推进。单个成功样本不代表所有来源可用。
- 针对性检查：47 项 JavaScript、50 项 Pester（Tauri、Identity、Web、Http、ApiRuntime）、16 项 Rust 通过，格式、编译和 NSIS 构建通过；安装包本机签名 Valid。缺少包资源的 APP 实测进入恢复页且不发送 `/api` 请求。
- CI 安装门禁新增固定端口全部占用的条件，按当前 APP 的启动报告发现端口并验证实时标识和数据目录；检查原有监听不受影响、正常退出后自有服务关闭。本地独立包启动与干净 Windows 静默安装仍是两项不同证据，后者以该 PR 的 desktop-build 为准。

## RC5：自然水形

- 主水滴改为偏斜的连续曲线，淡化整圈描边与浮雕阴影，用透明水体和断续反光连接背景。绘制、点击范围和水波裁切共享同一轮廓，避免视觉形状与实际交互区域不一致。
- 六颗小水珠的尺寸、宽高比、曲率和形变周期不同；只有水面缓慢变化，文字与点击区域保持稳定。保留七首推荐和选曲居中，小窗口收紧中心水珠高度。
- 音乐与点击水波共享连续曲率模型；播放波峰按音频能量产生，以不同相位舒展、减速、漂移和消散。无法采样的网络试听仍使用播放进度涟漪。浏览另一批推荐时水波继续，原点平滑移动，暂停及减少动态效果立即清空。
- 针对性验证：47 项 JavaScript、15 项 Web Pester、13 项 Rust 通过。实际 Tauri WebView 在 1440×900、1280×820、960×640 均保留七首，所有按钮中心可点击且无横向溢出；远程试听、选曲居中、点击水面换组、减少动态效果停止及恢复均已验证。
- 最终 NSIS 构建与本机签名验证通过；重新启动的隔离 APP 资源及 API 构建标识匹配最终打包内容。本地歌曲的真实采样水波、减少动态效果关闭及恢复也已实测。
- 桌面交互使用隔离 APP_HOME、曲库及临时服务端口。干净安装与完整启动/退出门禁由本轮 CI desktop-build 验证，不在用户 APP 运行期间执行静默安装。

## RC4：搜索恢复与播放水波

- 修复 HALF_OPEN 探测在异常结束后不释放、进程中断后不失效的问题。探测使用 15 分钟 SQLite 租约，过期后只允许一个新请求；普通失败进入有限恢复冷却，真正 HTTP 412/429 仍遵守指数冷却。搜索提示分别说明正在探测、恢复冷却和来源限流。
- 隔离状态复现了 9 月 2 日遗留的占用记录。实际 Tauri APP 恢复搜索后返回 20 条 B 站结果；喜欢 `BV15QQ3YbEqc` 后，经直接候选约 21 秒完成下载、校验与入库。此结果证明该故障已恢复，不代表所有视频的下载成功率。
- 翻页控件相对左侧音乐树居中；1280×820、960×640 的中心偏差均为 0 px，无横向溢出。下载动态使用深绿文字与浅色底，悬停、展开和键盘焦点保持可读。
- 日推音频能采样时，以真实能量驱动薄层水波向外扩散；不允许采样的远程音频使用轻柔的播放进度涟漪。暂停清空水波，缓冲期间不推进，减少动态效果时停止。音频采样只读副本，不改变播放输出。
- 针对性验证：46 项 JavaScript、138 项 Pester、13 项 Rust 通过。实际搜索、下载和水波测试均使用隔离 APP_HOME 与曲库。
- 最终 NSIS 构建成功，安装包本机签名状态 Valid；重新启动的隔离 APP 资源逐文件匹配最终打包目录，API 返回同一构建标识。真实音频水波在减少动态效果时清空，恢复后继续扩散；远程试听和暂停也已实测。
- 本机用户 APP 保持运行，既有服务占用全部默认端口对，因此实际 Tauri WebView 使用隔离服务的临时空闲端口完成交互验收。这不构成自动端口选择或完整安装生命周期的证明；干净安装、禁用源码后的启动与正常退出以本轮 PR 的 desktop-build 为准。本机没有运行会按进程名关闭用户 APP 的静默安装。

## RC3：雨中庭院与 B 站搜索

- 网络搜索增加 B 站，与网易云按来源隔离缓存，保留准确 BV 号和直接下载候选。元数据搜索不依赖下载组件；共享来源熔断与有界请求，限流时提示切换来源，不制造结果。UP 主单独展示，不充当歌手。
- B 站官方视频播放器在页内预览，收起或恢复底部音频会停止视频。实际 Tauri APP 搜索 `Candy_Wind 无仙` 得到 12 条有效结果，预览样本正常播放至结尾；点击喜欢后，所选 `BV1HMYb6KEPT` 经 bilibili_direct 约 19 秒完成下载、校验和入库。再次点击使用本地媒体接口，音频时间正常推进。后续补齐了 `2:7` 形式的时长解析，避免漏掉这类结果。
- 背景为持续细雨、落点涟漪与鼠标扰动，外围增加四段稀疏爬山虎；青绿水深、乳白反光和苔绿植物形成层次。设置按钮横向展开，头像降低不透明度并柔化边缘。
- 实际 APP 检查：960×640 无横向溢出且保留七片歌曲叶子；雨景在没有鼠标移动时持续变化，系统减少动态效果后画布保持静止、植物动画停止。
- 本轮针对性验证按最终套件去重：45 项 JavaScript、84 项 Pester、13 项 Rust 通过。NSIS 构建成功，本机签名状态 Valid。真实服务、状态和音乐样本全部使用隔离 APP_HOME。
- AGENTS.md 精简为 76 行项目边界和查阅入口；容易被误改的分系统约定收录在 `docs/engineering-contracts.md`，避免让每次任务都读取历史调试记录。
- 干净 Windows 安装与禁用源码后的启动、退出以本轮 PR 的 desktop-build 结果为准。本机用户 APP 正在使用，未执行会按进程名关闭它的静默安装。单个 B 站样本成功不代表所有视频可下载或所有账号均可预览。

## RC2：水面与网络搜索

- 音乐树增加六组随曲线移动的小叶和轻微摆动；背景改为缓慢折射的天光、云影与鼠标扰动，左右共享透明材质，收敛推荐水滴内的同心线条。减少动态效果的系统偏好会停止背景和装饰动画。
- 顶部操作加大间距，小窗口分两行；新手引导与歌词面板共用浅色材质，悬停和点击保持可辨认的浅色按钮。
- 输入继续筛选曲库，回车或「搜网络」打开网易云结果，支持试听和喜欢并下载。搜索后台有并发、超时、缓存和来源熔断限制，不阻塞曲库，也不替换日推。
- 实际 Tauri APP 搜索《青空 Candy_Wind》得到 20 首结果；点击喜欢后约 12 秒完成下载校验，文件出现在隔离曲库。复查发现无 Navidrome 时本地标识为空，已修复完成事务中的绑定，旧版本的文件记录也能恢复解析。再次点击结果已使用本地 `/api/library/.../stream`，音频时间正常推进。
- 本轮针对性验证：JavaScript 行为测试 43 项、Pester 82 项（按最终套件去重）、Rust 13 项通过；NSIS 构建与本机签名验证通过。真实 Tauri 检查涵盖页内搜索、下载状态同步、本地播放、歌词/引导材质、960×640 排版、服务标识及播放计数去重。
- GitHub 的干净安装、禁用源码后的启动和退出门禁以本轮 PR 检查结果为准。本机已有用户 APP 正在运行，NSIS 会按进程名检查它，因此本轮没有在用户会话中执行静默覆盖安装。

## 已实现

| 能力 | 行为与边界 |
| --- | --- |
| 空库与引导 | 14 首初遇歌单、每屏七首，试听 → 喜欢 → 下载结果；状态和偏好存 SQLite，设置可重开。 |
| 下载环境 | 一键准备固定版本，HTTPS、大小、SHA-256、版本及真实音频转换检查通过后原子启用；后台任务最多 10 分钟。 |
| 下载可靠性 | 缺组件不消耗重试次数；已知音源优先，失败后一次搜索回退；外部进程有超时；不以时长替代歌手证据。 |
| 音频完整性 | 独立暂存目录，不删除同名用户文件；检查媒体类型、时长和完整解码；重名入库使用唯一名称。 |
| 失败可处理 | 试听 15 秒上限，重试或换歌；喜欢不会因下载失败丢失；下载动态显示状态与重试入口。 |
| 名称与歌词 | 名称整理是显示偏好；同名歌词优先，联网查词有身份检查、租约与冷却。 |
| 数据恢复 | 一致性备份、升级前备份；停掉 APP 自己拥有的服务后验证备份，保存旧数据，刷新 WAL，再原子恢复；不移动音乐文件。 |
| 诊断 | 组件和操作进度可见；导出允许字段的 ZIP，不含原始日志、歌名、路径、Cookie、音频或数据库。 |

SQLite 仍是唯一运行时真源。快照和诊断只是备份、导出产物。组件固定来源、大小和校验值集中在 `Get-DownloadComponentCatalog`，独立安装在 APP_HOME，不随运行时更新覆盖。

## 发布验收边界

实际 Tauri APP 已验证：移除下载工具 PATH 后，一键准备全部组件；点击喜欢《青空》后约 8 秒完成下载校验、出现在音乐树并成功本地播放；手动备份后将显示模式改为 canonical，恢复后重新启动并回到 raw，同时生成恢复前的安全快照；诊断 ZIP 生成成功，960×640 没有横向溢出。桌面截图位于本地 `output/playwright/v1-care-960.png`。

GitHub 首轮的 api 和 desktop-build 均通过，后者完成干净 Windows 上的静默安装、源代码禁用后的启动、外置曲库、重启及服务退出检查。state 的一个旧测试在缺少组件的 CI 上仍期待消耗下载次数，已改成提供隔离的组件存在性夹具，并新增缺组件保留 WANTED/零次尝试的测试。最终以 PR 对应提交的 CI 为准。

Bilibili 限流、账号和资源限制仍可能使歌曲不可用，产品会有限回退并显示终态。跨机器安装信任、未参与开发的新用户试用、低性能机器与长期大曲库使用，不能由本机自动测试代替。当前自签名不代表所有 Windows 都信任；候选版供用户直接验收，再决定正式推广。
