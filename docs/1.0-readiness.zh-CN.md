# 从初遇到 1.0

评估日期：2026-09-13。开发版本：0.3.0-rc.1。以下区分已实现的能力、未完成的能力和仍需真实环境验证的门槛，不用代码量或主观百分比判断正式版。

## 这轮首次使用体验

- **空库也能开始**：首次打开准备 14 首「初遇歌单」，右侧每屏七首。准备元数据不联网、不下载音频；试听需要网络且可能受来源限制。没有偏好时保留起始歌单，形成喜欢/常听后，后续日推继续走偏好推荐。初遇歌单不冒充已经了解用户的个性化结果。
- **相遇 → 听见 → 留下**：用户主动点击才播放，实际开始播放后可以从引导点喜欢。喜欢使用原有事务入队接口；只有队列/本地状态确认完成才显示已下载。进度和收起状态存入 SQLite，设置可以重开。已有听歌/喜欢记录的用户不会被自动弹出的引导打断。
- **名称整理**：引导推荐开启正则显示，继续时才保存；已有偏好优先。原文件名、文件内容不变，设置可切回传统模式，识别仍标记 Beta。
- **自动歌词**：优先歌曲旁的同名 `.lrc`，然后同目录下 `Lyrics/`、`歌词/` 的同名文件。没有本地歌词时，依据明确的歌手和现有身份匹配规则联网查找。结果存在 SQLite，不覆盖用户文件；无法确认身份会说明原因。
- **有界的失败处理**：歌词按文件大小/修改时间失效，并发查找使用 60 秒所有者租约。成功缓存可离线读，网络或匹配不确定结果冷却 30 分钟，无可靠身份/无歌词冷却七天。播放不等待歌词，控制请求不等待网络查询。日志记录阶段、结果、异常类型、耗时。

实现入口：`MusicServer.Onboarding.psm1`、`web/onboarding.js`、`MusicServer.State.psm1`、`MusicServer.Providers.psm1`、`start_musicserver_ui.ps1`。`POST /api/onboarding` 只在当天为空时事务性填充；GET 只读，PUT 保存偏好和引导歌曲。后台日推返回空结果时不会清掉已有一天。

## 1.0 前必须闭环

| 优先级 | 当前证据 / 缺口 | 验收标准 |
| --- | --- | --- |
| P0 | 安装包只带 SQLite；下载仍需要机器已有 yt-dlp、ffmpeg、ffprobe。引导检查存在性，但不能自动安装，也未验证组件版本与功能健康。 | 干净 Windows 上无需命令行完成组件准备，固定可信来源和校验，显示进度与失败原因。实际完成「喜欢 → 下载 → 校验 → 入库 → 重启后播放」。 |
| P0 | 本轮抽查发现某些媒体 URL 最终 HTTP 200 却是 404 HTML，状态码不能证明能播放。起始曲目已筛选，静态筛选不能保证持续可用。 | 检查媒体类型和实际解码；试听失败能换来源或换歌。离线、412、限流、超时、无完整音源和错误录音都有可复现验证；无可用来源时明确结束。 |
| P0 | 队列已有事务、租约、回退、校验和重试覆盖；自动测试不能替代真实供应方验收。 | 人工核实中文、日文、多人演唱、同名异曲、现场/录音室样本，报告成功/不可用/误匹配和耗时。误匹配不接受；退出、断网、崩溃后不丢喜欢、不重复入库、不无限重试。 |
| P0 | 打包与持久数据隔离已有门禁；缺少普通用户可用的完整升级、备份恢复入口。 | 从发布版携带旧数据升级，验证收藏、播放记录、曲库设置保留；迁移失败可恢复，用户无需编辑 SQLite。 |
| P0 | 日志已分组件轮转、下载有失败原因；缺少易懂的一键诊断入口。 | APP 可显示组件健康、阻塞原因并导出脱敏诊断包；导出前说明包含内容，不含 Cookie、凭据、音频。错误可关联歌曲、阶段和一次操作。 |

## 发布前的体验验收

1. 请未参与开发的用户，分别在空库和已有曲库完成首次体验，观察能否自行找到试听、喜欢、歌词、下载动态和目录选择。
2. 验证 960×640、常见 DPI、键盘导航、长歌名、离线和不可用外置盘；低性能与减少动态效果环境有清楚的降级。
3. 在真实 WebView2 测大曲库启动、滚动、搜索、CPU/内存。现有 10,000 条 DOM 测试证明有限渲染，不能单独证明桌面性能。
4. 分开整理普通使用说明与历史脚本运维说明，下载依赖、来源限制和恢复入口必须可找到。
5. 完成外部机器安装信任测试。自签名产物在本机有效，不等于其他电脑的信任或 SmartScreen 信誉；正式渠道需确定签名与更新分发方案。

## 建议下一轮

优先做「下载环境自动准备 + 一键诊断」，随后由真实新用户验收完整下载闭环，再落实升级恢复与外部机器发布测试。更多皮肤、来源和装饰不作为 1.0 的必要条件；P0 未闭环前保留候选版标记。

## 验证边界

本轮自动检查覆盖空库准备、不覆盖已有日推、引导持久化、喜欢入队、本地歌词优先级、歌词缓存所有者与冷却、非法 HTTP 输入，以及相关 UI/下载/推荐/媒体回归。测试使用独立数据，不调用用户的下载队列。真实供应方下载成功率、干净机器依赖准备与跨机器证书信任仍待验收，不能由上述测试代替。
