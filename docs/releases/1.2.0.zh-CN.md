# MusicServer 1.2.0 · 曲库随行与轻盈启动

- 新增音乐库导出：将歌曲、相邻歌词、导入顺序、完整署名与已确认的收藏状态打包为 ZIP。新设备完整解压、在设置中选择该音乐文件夹并重启，即可自动校验并恢复。
- 迁移和导入顺序写入使用 SQLite 事务；扫描不会覆盖迁移的顺序与署名。导入期间切换文件夹会中止旧任务，失败不会写入部分状态，也不会重复排队下载。
- 日推根据导入的音乐库和收藏重新生成，包含 DailyMix 中的本地歌曲；保留录音室版本、歌词质量与歌手多样性的筛选策略。
- 修复歌名与歌手误识别，保留准确标题、演唱者和完整署名，拒绝以 Unknown 等占位值覆盖有效信息。
- 优先显示已有曲库索引，完整扫描在后台完成；冷启动播放不再依赖扫描整个曲库。增加诊断包和日志入口，可反馈启动、扫描、请求和日推生成的耗时与失败原因。
- 限制水面渲染尺寸，缓存缓慢变化的倒影；最小化或仅留托盘时暂停装饰动画，保留音乐播放和任务栏状态同步。后台计划任务使用隐藏、非交互方式启动。

## 升级与迁移

安装前请退出旧版。升级保留收藏、下载记录、歌词和本地音乐；选择文件夹不会移动、复制或删除原有音乐。

音乐库迁移入口位于设置的“下载与数据照料”。音乐库导出和应用数据备份是两个独立操作。反馈故障时使用“导出诊断包”；日志入口在启动失败时也可使用。

已经丢失的历史导入顺序无法从普通文件复制中还原，需要从仍保留原始顺序的设备导出。首次迁移会验证文件，耗时随曲库大小变化；导出和导入最多处理 25,000 首歌曲，每次任务限时 10 分钟。

安装包使用 MusicServer 自签名证书，其他电脑可能提示未知发布者。校验值随 Release 提供。完整发布验证结果以 Release 链接的 CI 为准。
